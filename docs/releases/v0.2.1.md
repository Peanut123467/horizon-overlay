# Horizon v0.2.1 — 四边三角与拖动实时预览

本次更新新增四边三角形参照，并修复拖动滑块时画面要等松手才更新的问题。

## 新增

- **四边三角**：屏幕四边各显示一个朝内的固定三角区域，独立开关，可与暗角、边框、准星共同使用。
- 支持**空心／实心**，四边统一调节；底边宽度和伸入深度分开调整，空心线宽与不透明度也可调，颜色跟随全局设置。
- 面板调节即时预览并自动保存，托盘“显示元素”中也可开关。默认关闭，开启后默认空心。

## 修复

- 连续拖动滑块时，预览和运行中的叠加层持续显示中间变化，无需等待松手。
- 后台刷新不会把正在调整的滑块和预览覆盖为旧值。
- 合并待处理的参数，限制同时进行的更新请求，避免慢速渲染积压旧画面；关闭面板前仍保存最后一次操作。

## 下载与升级

下载 **Horizon.exe**，或下载 **Horizon-v0.2.1-win64.zip** 后解压。退出正在运行的旧版，替换程序后双击打开即可；现有配置会保留。

打开后，在右侧开启“四边三角”，再点击“启动叠加层”。Windows 10／11，游戏使用无边框窗口或窗口模式。

`SHA256SUMS.txt` 提供下载文件的校验值。

Horizon 是本地画面辅助工具，不是医疗器械，不承诺缓解或治疗效果。
