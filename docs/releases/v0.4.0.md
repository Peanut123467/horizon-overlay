# Horizon v0.4.0 — 预设快捷使用

- 在预设卡片上录制 Ctrl 加字母、数字或 F1–F12，可同时按 Alt、Shift，Esc 取消，点击「清除」解除绑定
- 绑定前检查内部重复和其他程序占用，叠加层运行时注册失败会恢复原绑定
- 右键托盘进入「我的外观预设」，直接选择并显示快捷键，外观六项全部匹配时勾选
- 卡片「导出」生成单个 JSON，库标题「导入预设」添加方案，同名自动加后缀并生成新 ID
- 分享文件仅含格式标识、版本、名称、六项外观，不携带截图、快捷键或机器配置，限制 256 KB
- 重命名保留绑定，复制和导入不复制绑定，删除预设和恢复默认清理绑定
- 沿用原有配置和最多 50 个预设的独立本地库

## English

Assign or clear a Ctrl shortcut on each custom preset card, with duplicate and system conflict checks
Choose presets directly from the tray's My visual presets submenu; matching appearances are checked
Export and import one JSON preset at a time, with a new ID and an automatic suffix for duplicate names
Shared files contain only a name and visual settings, with no hotkeys, screenshots or machine settings
Renaming keeps the binding; copying and importing do not copy it; deletion and reset clear it
Existing configuration and preset libraries remain compatible; the application UI remains Chinese

## 日本語

各カスタムプリセットに Ctrl ショートカットを登録・解除でき、重複と他のアプリによる使用を確認します
トレイの「我的外观预设」から直接選択でき、外観が一致するとチェックが付きます
個別の JSON プリセットを共有でき、読み込み時に新しい ID を生成し、同名には接尾辞を付けます
共有ファイルには名前と外観だけが含まれ、ショートカット、スクリーンショット、端末設定は含まれません
名前変更では登録を維持し、複製・読み込みでは引き継がず、削除・初期化では解除します
既存の設定とプリセットライブラリに対応し、アプリの UI は引き続き中国語です
