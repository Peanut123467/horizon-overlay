## 新增与界面更新

- **全新控制面板**：采用深蓝灰与暖色强调的暮色地平线界面，放大左侧预览区，右侧集中外观和应用设置，常用参数默认展开
- **游戏截图对比**：导入 PNG、JPEG 或 WebP 图片，直接拖动预览中间的圆形手柄比较原图与叠加效果，也可使用方向键调整或关闭对比
- **自定义外观预设库**：保存、应用、复制、重命名和删除自己的方案，提供缩略图，最多保存 50 套，删除前需要确认
- 外观预设保存暗角、边框、四边三角、中心准星、锚点阵和颜色，不改变显示器、快捷键、统计、休息提醒或启动设置
- 精简标语、页脚声明和参数组介绍等非必要小字，保留操作、状态和错误提示；面板主题色与叠加层颜色独立

## 修复与数据保护

- 切换截图时丢弃旧背景的预览结果，避免较慢的请求覆盖新画面
- 截图保留比例和方向，透明图片统一合成背景；取消选择或导入失败时保留当前预览
- 截图只用于本次窗口预览，不上传、不写入配置或预设；预设缩略图使用模拟场景
- 预设库单独保存在 `profiles.json`，采用原子写入；发现格式、字段或数值损坏时提示错误并保留原文件
