# Horizon 本地控制面板

双击项目 `dist/Horizon.exe`。启动时只显示控制面板，点击右上角“启动叠加层”后才会启用屏幕遮罩。

面板左侧为模拟预览、预设与颜色，右侧为具体参数，两个区域均可向下滚动。设置会自动保存；更改显示器也即时生效。预览使用模拟画面，并非游戏截图。

点击右侧参数组标题可像抽屉一样展开、收起；组开关单独控制功能启用，不会收起参数。位置、显示器等下拉菜单也有抽拉动效；按钮点击时有轻柔、较慢的果冻回弹动效；系统开启减少动画时会关闭动效。

首次启动和“恢复默认”的外观使用“标准”预设：暗角 0.34 / 1.06 / 0.55，边框 26 / 8 / 90，准星 9 / 9 / 150。休息提醒默认 60 分钟、停留 3 秒，统计字号 21。

右上角可以显示/隐藏或停止叠加层。关闭控制面板后，已启动的叠加层继续在托盘运行；右键托盘中的“打开控制面板”可以再次打开窗口。“停止叠加层”会退出后台叠加层，控制面板仍可继续调整、保存配置。

右侧底部可录制快捷键：点击键位后按下 Ctrl 加字母、数字或 F1–F12，可以同时按 Alt、Shift；Esc 取消。重复组合与其他程序占用会显示提示。内置默认键位保留原有备用键回退行为。

左侧底部提供 JSON 配置导入、导出，以及登录 Windows 后打开控制面板的开关。自启默认关闭，仅在用户操作开关后更改当前用户的启动项。

配置保存在 `%APPDATA%\horizon\config.json`，不联网、不上传，也不修改游戏文件。Windows 需具备 WebView2 Runtime；Windows 11 和大多数安装了 Edge 的 Windows 10 已有此组件。

## 从源码运行

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[dev]" pyinstaller
.venv\Scripts\python.exe -m horizon
```

只运行后台叠加层可使用 `python -m horizon --overlay`，指定配置用 `--config 路径`。原有带 `--preset`、`--monitor`、`--color` 等叠加层参数的命令继续直接启动叠加层。`--console` 明确打开控制面板。

## 验证与打包

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\ruff.exe check src tests tools
.venv\Scripts\ruff.exe format --check src tests tools
.venv\Scripts\python.exe tools/console_smoke.py
.venv\Scripts\python.exe tools/integration_smoke.py
.venv\Scripts\python.exe tools/build_exe.py
.venv\Scripts\python.exe tools/exe_smoke.py
```

集成检查和可执行文件检查需先关闭正在运行的 Horizon，检查使用独立配置。界面检查会自动打开并关闭测试窗口。自启开关的真实登录效果、游戏中的实际体验和其他机器上的运行仍需人工验收。
